# 聊天 UI 与交互调整：2026-10-15

已部署到 ECS，并安装荣耀 **0.3.0 / versionCode 5**。方向为接近 ChatGPT App 的核心操作逻辑，保留 Codex、电脑及项目的真实业务范围。

## 调整

- 单一聊天主界面：浅色/深色/跟随系统，用户气泡、平铺回答、列表及代码块；回答和代码分别可复制。
- 左侧会话抽屉：历史、搜索、新聊天、项目/电脑选择、设置；支持边缘滑动、点击遮罩和系统返回关闭。
- 新聊天先打开空白页，首条消息才创建实际会话；发送后立即回显，生成时提供停止按钮。
- 会话分别保存当前页生命周期内的草稿和滚动位置；切换不会中断生成。自动恢复上次选择的会话 ID，不在云端持久化聊天正文。
- 底部输入栏自适应高度和软键盘；桌面 Enter 发送、Shift+Enter 换行，手机 Enter 换行；图片先预览，可移除，发送时再暂存。
- 跟随最新消息时自动滚动；上翻阅读后停止自动滚动，提供回到底部按钮。历史先显示最新一页，旧消息向前加载。
- Android 移除上下大块调试按钮和永久地址栏，连接配置、主机切换、刷新和日志收进右上角原生菜单；保留双 WebView，不增加 JS 原生桥。
- 处理快速完成后发送确认才返回、重复 SSE、延迟快照、未知写回执、原生索引迟迟未包含新会话等边界。未知写任务仍需显式核对，不能自动换 ID 重发。

未添加不具备业务支持的语音、重新生成、会话删除等入口；继续使用只读隔离验证，不扩展执行权限。
