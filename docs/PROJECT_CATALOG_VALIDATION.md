2026-10-15：Mac 执行器从 Codex 桌面本地项目元数据只读加载项目，不再把公开项目清单限制为隔离验证目录。当前发现 45 个本地项目，额外保留 1 个隔离验证入口。Windows 仍需启动对应电脑的执行器，ChatGPT 云项目不属于本机 Codex 执行器。

## 实现

- `business/src/projects.mjs` 只读 `$CODEX_HOME/.codex-global-state.json`（未设置时为 `~/.codex`），读取 `local-projects`、`project-order`、`thread-project-assignments`。旧桌面仅有 workspace roots 时采用兼容读取，不递归扫描用户文件系统。
- 保留项目原有稳定 ID 与名称。同一目录的多个命名项目分别显示，会话优先按桌面显式项目归属分组；无显式归属的旧会话按工作目录回退到一个项目。显式归属支持工作树会话。手机创建会话的项目归属由独立执行器回执恢复，不写入 Codex 项目配置。
- 项目元数据每次任务执行时重新读取。在项目面板点击刷新即可同步增删和名称；新建或回复仍采用现有 read-only 配置。
- 全部会话索引在 Mac 进程内缓存 30 秒，切换项目复用，分页重复 ID 去重；项目刷新会清空索引缓存。该缓存不发送至服务器落盘。
- 云端仅得到项目 ID、名称、目录可用标志；本机路径和桌面原始状态不上传。
- App 点击顶部项目名称或侧栏“项目”打开项目面板，支持搜索、选择、置顶和取消置顶。置顶项目位于上方，新置顶项目排在最前。
- 置顶仅写当前 WebView 来源的 localStorage，键 `rmt-project-pins:v1:<deviceId>`；Mac 与 Windows 独立。刷新、重开 App 可保留；清除 App 数据或切换服务域名后不会迁移。置顶操作不调用业务 API、不写 Codex，也不改变桌面项目排序。
